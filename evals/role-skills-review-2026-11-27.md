# Role skills preview review — 27 November 2026

## Baseline and limits

A fresh-context agent, without these skills, considered four fictional cases: duplicate dashboard requests, clicks increasing while qualified leads fell, faster packing with slower dispatch, and completed training with missing access. Its baseline responses already recognized the key uncertainties and proposed appropriate investigation. No baseline failure was observed, so this exercise does not establish that the new skills improve model behavior.

## Independent interpretation review

A separate fresh-context agent read the four skills and their guides/templates without the evaluation table. It simulated eight cases: the four above, plus prototype praise without usage, copy approval without budget authority, automation with unreliable inputs/exceptions, and a polished AI-written learner submission.

All eight response plans respected evidence limitations and action boundaries. No contradictory instructions were found. Review identified two wording risks: the operations description might exclude requests to optimize one step, and references to stakeholder consultation might imply unauthorized contact. Wording was clarified to accept such optimization requests for end-to-end analysis, and to distinguish proposed questions from authorized communication. Approval documentation was also made explicitly proportional to task size.

This is a reasoning review, not execution of campaigns, process changes, employee assessments, or code on either target host. Live Claude Code and Codex trials remain pending.

## Static and UI checks

All four skill folders passed the bundled validator. Local Markdown links resolved and Git whitespace checks passed.

The offline HTML demo was exercised in isolated headless Google Chrome through Playwright. Checks covered four role selections, both invocation formats, three output views, review/reset state, and mobile overflow at 390px. No page JavaScript errors or HTTP(S) requests occurred. Desktop and mobile screenshots were visually reviewed. Scripted UI behavior is not evidence of agent effectiveness or real-world impact.
