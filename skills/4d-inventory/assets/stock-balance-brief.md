# Stock Balance brief: <decision> · <variant> / <location>

<store> · <date> · data: full | sales only | none

Keep only the fields that carry something. The answer comes first.

| Field | Content |
| --- | --- |
| Do this / Verdict | The action or verdict in one line, with the number and its range. For a forecast: trust · trust with an adjustment · don't trust yet. |
| Why this number | The formula with the actual values, for example: reorder point = (21 days + 9 safety days) × 3.4/day = 102. |
| This might seem wrong because | Only when the answer goes against intuition: what the merchant expected and why the data says otherwise. |
| Leans | Availability or Cash, and what it costs the other side. |
| Inputs checked | Each check as pass, fixed (with the adjustment) or could not run (with the missing field). |
| Seen | What the data shows directly. |
| Inferred | What was concluded or assumed, and what would confirm it. |
| Guardrail | The opposite-side measure and its limit. |
| Look again | The review date, and what result means keep, adjust or stop. |
| Ruled out | Optional: the obvious alternative and why it was not chosen. |
| Without the checks | Optional: what the unchecked numbers would have given, and what would have gone wrong. |

This brief advises. It does not create a purchase order or change any setting; the merchant acts on it.
